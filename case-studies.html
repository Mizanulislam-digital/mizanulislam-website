Analytics 2026 · GTM + GA4 + Zaraz

Complete Analytics Stack — GTM + GA4 + Cloudflare Zaraz

Built end-to-end server-side analytics on a custom static site. Used Cloudflare Zaraz for server-side event execution, bypassing CSP restrictions and browser cookie limits. Includes custom CTA and form tracking.

Stack Components

  • Cloudflare Zaraz (server-side tag management)
  • Google Tag Manager (v4 published)
  • GA4 property with Web data stream
  • Custom event tracking (cta_click, form_submit, tool_used)
  • Server-side event execution — no client JS required

Problems Solved

  • CSP syntax errors blocking GTM loading
  • Missing GA4 Event tag (Config alone doesn't track)
  • Client-side tracking blocked by browsers
  • Cookie consent + tracking conflicts
  • Server-side bypass of CSP restrictions
Tools: Cloudflare Zaraz Google Tag Manager GA4

Infrastructure 2026 · Migration

Blogspot → Cloudflare Pages Migration

Migrated from an older Blogspot site to a fully custom-coded static site on Cloudflare Pages. Preserved SEO value through canonical URLs, 301 redirects, and clean URL architecture. Hardened security with proper CSP.

Migration Challenges

  • Old Blogspot URLs still in Google's index
  • Handling duplicate content issues
  • Preserving SEO equity across migration
  • Rebuilding all tracking from scratch
  • Hardening security headers

What Was Implemented

  • _redirects file with 301 rules for old URLs
  • Canonical tags on every page
  • Hardened Content Security Policy (CSP)
  • Clean URL architecture (no .html extensions)
  • Free global hosting via Cloudflare Pages
Stack: Cloudflare Pages GitHub CSP Headers
