Educational Playbooks

Case Study Frameworks

Structured approaches from basic tracking to advanced scaling — how I think about paid growth. Not fabricated client win reports.

Authenticity note: I am early in client delivery. These are method frameworks and educational walkthroughs — not claimed results from named clients. When real projects complete (with permission), measurable outcomes will be published here. Until then, judge the process, not invented ROAS numbers.
Level 1

Basics — Foundation Before Spend

Basic

Pixel + Event Map Before First Ad

Most wasted spend starts with broken or incomplete tracking. Map events before you open the ad account.

  • Install Meta Pixel + base pageview
  • Define Lead / Purchase / AddToCart events
  • Test with Meta Events Manager (Test Events)
  • Confirm thank-you page fires once
Event fire rate Duplicate check Test mode pass
Basic

UTM Hygiene for Every Campaign

Without clean UTMs, you cannot tell which ad or channel drove the lead. Standardize naming from day one.

  • utm_source = platform (facebook, google)
  • utm_medium = cpc / paid_social
  • utm_campaign = offer or launch name
  • Store links in a sheet; never improvise only in Ads Manager
Attribution clarity GA4 source/medium
Basic

Landing Page–Ad Message Match

If the ad promises X and the page talks about Y, conversion drops. Align headline, offer, and CTA with the creative.

  • Copy ad primary text into page H1 intent
  • One primary CTA above the fold
  • Mobile load under ~3s on mid-range 4G
  • Form: only fields needed for the first step
Bounce rate CVR Form starts
Basic

Budget Guardrails for New Accounts

New advertisers often overspend before learning. Cap daily budget and define kill rules before launch.

  • Daily cap you can afford to learn with
  • Kill rule: 2–3× target CPA, zero conversion → pause
  • Review every 48–72 hours early on
  • Do not scale until tracking is trusted

Level 2

Intermediate — Structure & Testing

Intermediate

Meta ABO Creative Test System

Isolate variables. Test hooks and angles in ABO with equal budgets, then promote winners.

  • 3–5 creatives, one primary angle each
  • Same audience / placement rules across ad sets
  • Enough spend to read signal (not 1-day guesses)
  • Kill clear losers; keep 1–2 winners for scale
CTR / CPC CPA Hook rate
Intermediate

Google Search Intent Structure

Separate high-intent from research queries. Negatives protect budget from irrelevant clicks.

  • Group keywords by intent (buy vs learn)
  • Match types intentional — not all broad by default
  • Weekly search term review + negatives
  • Landing page aligned to the query theme
CPA Quality Score Wasted spend %
Intermediate

CRO Five-Point Page Audit

Before new creatives, fix the page. Five checks often move conversion without a full redesign.

  • Headline matches ad promise
  • One primary CTA
  • Proof near the fold
  • Form friction reduced
  • Mobile speed and layout stability
CVR Scroll depth Form complete %
Intermediate

Retargeting Without Overlap Chaos

Simple funnel stages beat complex overlapping audiences that compete with each other.

  • Site visitors 7–30d (exclude converters)
  • Frequency caps so users are not over-exposed
  • Creative: reminder + offer clarity
  • Exclude recent converters from cold/retarget overlap
Frequency CPA retarget
Level 3

Advanced — Tracking & Scale Systems

Advanced

Meta CAPI + Pixel Deduplication

Browser pixel alone loses signal (iOS, blockers). Server events + shared event_id recover quality.

  • Browser pixel + CAPI both send key events
  • Same event_id on both paths for dedupe
  • Hash email/phone when available (SHA-256)
  • Watch Event Match Quality trends in Events Manager
EMQ trend Event coverage
Advanced

ABO → CBO Scale Path

Test in ABO for control. Move proven creatives into CBO and raise budget in steps — not sudden 5× jumps.

  • Promote winners only after stable read
  • CBO lets Meta allocate across ad sets
  • Increase budget ~20–30% every few days when stable
  • Watch frequency, CPA, and MER — not CTR alone
ROAS / MER CPA at scale Frequency
Advanced

Server-Side Path (When Needed)

Server-side GTM or a lightweight server endpoint improves first-party control vs client-only tags.

  • Decide if volume/privacy needs justify the setup
  • Forward purchase/lead from server with consent rules
  • Keep client pixel where it still adds value
  • Document the pipeline for handoff
Server event rate Consent compliance
Advanced

WhatsApp Post-Click Nurture

Paid traffic that lands on WA without UTM discipline is hard to measure. Treat WA as a tracked channel.

  • WA links with UTM (or unique landing → WA)
  • Approved templates for first response
  • Tag leads by campaign in CRM / sheet
  • Respect opt-in and timing — no spam
Reply rate Lead → booked call
